# 树状架构开发方法论

> 不是代码堆砌，而是程序生长。
> PP

──

## §1 核心理念：为什么是树？

软件开发最本质的三个问题，树状架构逐一回答：

| 问题 | 树的回答 | 反例（堆砌） |
|------|---------|-------------|
| 我们现在在哪？ | 树干→分枝→叶片，精确位置 | 散落文件夹，靠记忆定位 |
| 我们要去哪？ | 北极星（树干）决定方向 | 每周换目标，代码推倒重来 |
| 下一步做什么？ | 当前分枝上未闭环的叶子 | 随机挑 bug 修，优先级混乱 |

**树的四条铁律：**

1. **树干不变** —— 项目北极星目标，一句话定义，除非战略级调转否则永不修改
2. **分枝闭合** —— 每个版本/阶段完成后锁死，不回溯、不重构、不修枝
3. **叶片独立** —— 每个文件只做一件事，文件名即职责
4. **原位生长** —— 新代码只能长在当前分枝的叶片上，不能跳枝

---

## §2 树干（北极星）

**一句话定义项目为什么存在。**

标准：
- 必须是一句话（≤ 30 字）
- 必须可验证（"实现了/没实现"可以判断）
- 必须唯一（不能是"做一个好用的工具"这种万能句）

**Paladin 的树干：**
> 从会执行 → 会创作 → 会进化，让 AI 成为架构本身。

**空模板：**
> [项目名]：从 [起点] → [中点] → [终点]，[独特价值]。

---

## §3 分枝（阶段）

**每个阶段 = 可独立验证的里程碑。**

规则：
- 每个分枝必须有清晰的前置条件（上枝闭合后才可进入）
- 每个分枝必须有唯一的出口标准（可验证/可展示）
- 分枝数控制在 3~5 个，不超过 7 个

**Paladin 的三枝：**

```
树干：会执行 → 会创作 → 会进化
  ├── 🌱 会执行 (v0.1-v0.7)    ← 已闭合
  ├── 🌿 会创作 (v0.8)         ← 当前分枝
  └── 🌳 会进化 (v1.0)         ← 下一枝
```

**空模板：**
```
树干：[北极星]
  ├── 阶段 1：[名称]    ← [状态]
  ├── 阶段 2：[名称]    ← [状态]
  └── 阶段 3：[名称]    ← 下一枝
```

## §4 叶片（文件）

**每个文件只做一件事。**

规则：
- 每个文件对应一个明确的职责（文件名即函数名/类名）
- 每片叶只能属于一个分枝
- 叶数控制在 3~5 片/枝，叶过大则拆枝，叶过小则合并

**Paladin v0.8 的叶片：**

```
🌿 会创作 (v0.8)
  ├── v0.8.1 生成工具
  │   ├── protocol.py    → MetaAction 协议
  │   ├── codegen.py     → 代码生成器
  │   └── planner.py     → 缺位检测 + 触发合成
  ├── v0.8.2 热加载
  │   ├── loader.py      → importlib.util 动态加载
  │   └── executor.py    → meta_actions 优先
  └── v0.8.3 持久化
      ├── codegen.py     → save_to_file()
      ├── generated_tools/ → 磁盘目录
      └── app.py demo    → 场景验证
```

**空模板：**
```
阶段 [名称]
  ├── 子阶段 1：[名称]
  │   ├── [文件名] → [职责]
  │   └── [文件名] → [职责]
  └── 子阶段 2：[名称]
      ├── [文件名] → [职责]
      └── [文件名] → [职责]
```

## §5 修剪（迭代原则）

**每次迭代只动当前分枝的叶子。**

| 情况 | 操作 | 禁止 |
|------|------|------|
| 当前分枝未闭环 | 摘剩下叶子 | 跳下一枝 |
| 当前分枝已闭环 | 进入下一枝 | 回溯修旧枝 |
| 需要新功能 | 在当前枝上长新叶 | 开新枝 |
| 发现错误 | 修当前叶 | 改其他枝的叶 |

---

## §6 反模式对照表

| 堆砌模式（❌） | 树形模式（✅） |
|---------------|--------------|
| "先写着，后面再重构" | "先画树，再落第一片叶" |
| "这个功能以后可能用上" | "这个功能属于哪枝？不在树上就不写" |
| "改一个文件顺便修另一个" | "只动当前分枝的当前叶" |
| "版本推进不顺就回溯" | "分枝锁死后不回溯" |
| "新功能直接叠加上去" | "找到对应分枝，长新叶" |

## §7 快速启动模板

```
🌳 [项目名]
│
├── 🌱 阶段 1：[名称]    ← [未开始 / 进行中 / 已闭合]
│   ├── [文件名] → [职责]
│   ├── [文件名] → [职责]
│   └── [文件名] → [职责]
│
├── 🌿 阶段 2：[名称]    ← [未开始 / 进行中 / 已闭合]
│   └── ...
│
└── 🌳 阶段 3：[名称]    ← 下一枝
    └── ...
```

**用法：** 新项目启动时，花 10 分钟填完这个模板。填不满说明需求还没想清楚——不要写代码。
